# 🐒 CHIMP SODA — Unleash Your Primal Fizz

> **"Crafted for modern primates who reject boring water and synthetic junk."**

Chimp Soda is a bold, high-energy prebiotic & adaptogenic craft sparkling soda brand website. Engineered with rich aesthetics, real-time audio synthesis, dynamic 3D-tilt can showcase, canvas fizz particle physics, and interactive shopping features.

---

## ⚡ Key Features

- **🥫 Interactive 3D Can Showcase**: Smooth mouse-driven 3D perspective tilt and levitating ingredient badges.
- **🎨 Dynamic Flavor Theming**: Instant palette and background aura shifts between **Psycho Banana**, **Primal Berry**, **Mango Gorilla**, and **Electric Yuzu**.
- **🔊 Procedural Web Audio Engine**: Synthesizes realistic can-crack ("K-TSHHH!") and effervescent bubble pops with zero external audio assets. Includes audio toggle switch.
- **🫧 Ambient Bubble Particle Canvas**: Organic floating micro-bubbles with mouse repulsion and click-to-burst spark physics.
- **🎯 "Primal Vibe" Flavor Finder Quiz**: 3-question interactive selector that matches users with their spirit soda.
- **🛒 Slide-Out Cart Drawer**: Full quantity management, promo code engine (try `CHIMP15`), free shipping threshold meter, and order checkout simulation.
- **📱 Fully Responsive**: Tailored for mobile, tablet, and desktop viewports.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local HTTP server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node / npx
npx serve .
```

Then visit `http://localhost:3000`.
